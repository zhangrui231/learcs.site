## 课程简介

大语言模型已经将软件开发从以手工编码为主的过程，转变为开发者与日益强大的编码 Agent 协作的过程。这一转变要求我们以新的方式定义意图、组织工作并协调工具，使 Agent 能在复杂软件项目中有效参与。

**CS146S: The Modern Software Developer** 是斯坦福大学开设的一门课程（Fall 2026），探讨 AI 原生软件开发的新兴实践与技术，包括：

- **MCP（Model Context Protocol）** —— 模型上下文协议
- **Agent Skills** —— Agent 技能体系
- **Spec-Driven Development** —— 规格驱动开发
- **Loop Engineering** —— 循环工程
- **Software Factory** —— 软件工厂

学生将学习如何为 Agent 提供正确的上下文与能力、将产品需求转化为可执行的规格说明，并设计人类与 Agent 共同规划、构建、评估和改进软件的迭代工作流。

通过动手作业、项目和来自行业从业者的讲座，学生将探索当前编码 Agent 的能力与局限性。课程结束时，学生将能够设计有效的 Agent 驱动工作流、将工具与技能组合为可靠的开发系统，并应用软件工厂原则以更快的速度和更大的规模构建与演进软件。
