## 课程作业

本目录包含 CS146S 课程全部五周作业的中文翻译。每周作业包含两部分：

- **assignment.md** —— 作业说明，包括任务要求、评分标准和学习目标
- **writeup.md** —— 报告模板，你需要填写其中所有的 `TODO`

> **原文仓库**：[mihail911/modern-software-dev-assignments](https://github.com/mihail911/modern-software-dev-assignments)

## 作业总览

| 周次 | 主题 | 核心任务 |
|---|---|---|
| [第一周](/docs/curriculum-resource/cs146s/homework/week1/assignment) | 真实 Claude Code 会话的追踪剖析 | 用代理捕获 Claude Code 的 HTTP 请求并深入剖析 |
| [第二周](/docs/curriculum-resource/cs146s/homework/week2/assignment) | 为第三方 API 构建 MCP 服务器 | 构建 MCP 服务器、OAuth 流程与 Agent 人机工程学 |
| [第三周](/docs/curriculum-resource/cs146s/homework/week3/assignment) | 编写一个技能 | 编写 Agent 技能并验证其触发与执行 |
| [第四周](/docs/curriculum-resource/cs146s/homework/week4/assignment) | 让混乱的仓库变为 Agent 就绪 | 编写 AGENTS.md 或 CLAUDE.md 配置文件 |
| [第五周](/docs/curriculum-resource/cs146s/homework/week5/assignment) | Agent 就绪度报告 | 使用 Factory 的 Agent 就绪度报告评估三个开源仓库 |
