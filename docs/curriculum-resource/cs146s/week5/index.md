## 本周主题

**Agent-Ready Codebases —— Agent 就绪的代码仓库**

本周探讨什么让一个代码仓库对 Agent 友好：结构、文档、测试和检查，以及如何评估和改进仓库的就绪度。

### 核心议题

- 什么让仓库 Agent 就绪：结构、文档、测试和检查
- 评分和审计就绪度
- 在真实仓库中阻碍 Agent 的常见缺陷
