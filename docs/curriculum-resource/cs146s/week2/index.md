## 本周主题

**Advanced Context Engineering —— 高级上下文工程**

本周探讨高级提示技巧、规格驱动开发框架（RePPIT）、MCP 基础知识，以及如何为 Agent 设计符合人机工程学的工具接口。

### 核心议题

- 高级提示技巧，以及各自适用的场合
- RePPIT（研究、提案、规划、实现、测试）与规格驱动开发
- MCP 基础：服务器、客户端、工具与传输
- 为 Agent 的使用体验设计工具
