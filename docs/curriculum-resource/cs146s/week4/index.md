## 本周主题

**Customizing Your Agent and Repository —— 定制你的 Agent 与代码仓库**

本周探讨如何通过配置文件（CLAUDE.md、AGENTS.md）、Hooks 机制和子 Agent 模式来定制 Agent 行为，使其更好地适配你的代码仓库和团队工作流。

### 核心议题

- CLAUDE.md 和 AGENTS.md：什么该放哪里
- 用于 lint 闸门、测试运行和护栏的 Hooks
- 子 Agent 模式（规划器 / 实现器 / 审查器）
