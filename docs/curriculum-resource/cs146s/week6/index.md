## 本周主题

**Agentic Code Review —— Agent 化代码审查**

本周探讨 AI 驱动的代码审查：它能抓住什么、会漏掉什么，如何设计审查架构，以及如何将 AI 审查融入团队的 PR 工作流。

### 核心议题

- AI 审查擅长抓什么，以及会漏掉什么
- 审查架构和自定义规则
- 将 AI 审查融入团队的 PR 工作流
